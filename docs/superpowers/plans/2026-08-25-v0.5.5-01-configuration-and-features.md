# MADS.rs v0.5.5 Configuration and Feature Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add backward-compatible string-array configuration with path provenance and establish feature boundaries that let JWT build without Axum or Diesel.

**Architecture:** `ConfigSource::load` remains the scalar compatibility contract while a defaulted `load_document` carries scalar and string-array values through the same deterministic merge and interpolation pipeline. Every winning value retains a source label and optional relative-path base. Cargo features make HTTP, database, JWT, and cookies independently composable while preserving today's default `common` behavior.

**Tech Stack:** Rust 2024, Rust 1.85.0, TOML 0.8.23, `toml_edit` 0.22.27, `dotenvy` 0.15.7, Cargo feature resolver 3, `cargo_metadata` 0.19.

**Spec:** `docs/superpowers/specs/2026-08-25-v0.5.5-passport-jwt-and-cookies-design.md`

## Global Constraints

- Keep workspace edition 2024 and MSRV Rust 1.85.0.
- Keep `mads-core` free of Axum, HTTP, cookie, JWT, cryptography, Diesel, and PostgreSQL normal dependencies.
- Keep `ConfigSource::load(&self) -> Result<BTreeMap<String, String>>` source-compatible through a defaulted `load_document` method.
- TOML arrays may contain strings only; reject mixed, nested, table, integer, float, boolean, datetime, and array-of-table array values with `MADS020`.
- Preserve exact, non-recursive `${NAME}` interpolation; dotenv values are interpolation inputs only and process environment wins.
- Preserve explicit configuration loading; never auto-load `.env`, `mads.toml`, or process variables in `Mads::builder()`.
- Preserve redaction: configuration values and array elements never appear in `Debug`, diagnostics, or reports.
- `EnvSource` stays scalar-only; arrays come from TOML or programmatic `ConfigDocument`/`MapSource` construction.
- A later source replaces an earlier value completely even when its shape changes between scalar and array.
- Relative TOML paths resolve from the TOML parent's directory; environment and programmatic paths resolve from the process working directory.
- Keep default facade behavior backward-compatible: default `common` continues to enable existing HTTP and database APIs, but does not enable JWT or cookies.
- A `jwt`-only normal dependency graph must contain no Axum, `axum-extra`, Diesel, `deadpool-diesel`, or `diesel_migrations`.
- Keep `#![forbid(unsafe_code)]`, public rustdoc, `clippy::all = "deny"`, and the 85% line-coverage gate.
