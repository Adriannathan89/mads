# MADS.rs v0.2 Dependency Graph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship MADS.rs 0.2.0 with side-effect-free provider-graph analysis, aggregated validation, deterministic topological planning, and automatic application-scoped construction before startup.

**Architecture:** Compile-time macros continue to emit static descriptors. New focused graph modules in `mads-core` normalize those descriptors with explicitly supplied values, validate the complete provider catalog, compute a deterministic sequential plan, and retain immutable inspection data in the built application. The existing registry remains the runtime value store; the builder tracks whether registered values were provided or manually preconstructed.

**Tech Stack:** Rust 2024, Rust 1.85 MSRV, `inventory`, procedural macros using `syn`/`quote`, Tokio tests, `trybuild`, GitHub Actions, and `cargo-llvm-cov`.

---

## Global Constraints

- Follow red-green-refactor: run each focused test before implementation and observe the expected failure.
- Keep `mads-core` free of Axum, Diesel, `mads-common`, and `mads-extra` dependencies.
- Use concrete `TypeId` bindings only; do not add traits, qualifiers, names, scopes, module edges, or reachability.
- Analyze the entire provider catalog and validate it before invoking any automatic constructor.
- Keep construction sequential and deterministic.
- Preserve `MadsBuilder::construct::<T>()` as a manual escape hatch.
- Every Rust file starts with `//!`; every public item has `///`; unsafe code remains forbidden.
- Preserve Rust 1.85 and at least 85 percent workspace LLVM line coverage.
- Use `apply_patch` for hand-written changes and stage only files belonging to the current task.

```rust
#[derive(Debug)]
pub struct Error {
    diagnostics: Vec<Diagnostic>,
    source: Option<Box<dyn std::error::Error + Send + Sync>>,
}

impl Error {
    pub fn new(diagnostic: Diagnostic) -> Self {
        Self { diagnostics: vec![diagnostic], source: None }
    }

    pub fn from_diagnostics(
        primary: Diagnostic,
        related: impl IntoIterator<Item = Diagnostic>,
    ) -> Self {
        let mut diagnostics = vec![primary];
        diagnostics.extend(related);
        Self { diagnostics, source: None }
    }

    pub fn with_source<E>(diagnostic: Diagnostic, source: E) -> Self
    where
        E: std::error::Error + Send + Sync + 'static,
    {
        Self { diagnostics: vec![diagnostic], source: Some(Box::new(source)) }
    }

    pub fn code(&self) -> DiagnosticCode {
        self.diagnostics[0].code()
    }

    pub fn diagnostic(&self) -> &Diagnostic {
        &self.diagnostics[0]
    }

    pub fn diagnostics(&self) -> &[Diagnostic] {
        &self.diagnostics
    }
}

impl fmt::Display for Error {
    fn fmt(&self, formatter: &mut fmt::Formatter<'_>) -> fmt::Result {
        for (index, diagnostic) in self.diagnostics.iter().enumerate() {
            if index > 0 {
                formatter.write_str("\n\n")?;
            }
            diagnostic.fmt(formatter)?;
        }
        Ok(())
    }
}
```

```rust
pub async fn build(mut self) -> Result<Mads> {
```
