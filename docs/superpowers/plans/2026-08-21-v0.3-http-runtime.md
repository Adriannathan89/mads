# MADS.rs v0.3 HTTP Route Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship MADS.rs 0.3.0 with fail-closed application route validation, typed controller dispatch, Axum router/server execution, standard extractors, and basic HTTP responses.

**Architecture:** `mads-core` remains HTTP-free while `mads-common` becomes the Axum 0.8 adapter. Route macros emit immutable metadata and typed registrar code; HTTP bootstrap validates every descriptor before invoking registrars, building a router, starting lifecycle hooks, or binding a listener. Controllers are resolved once from the v0.2 application context and captured through their existing cheap `Arc`-backed handles.

**Tech Stack:** Rust 2024, Rust 1.85 MSRV, Axum 0.8, axum-extra typed headers, Tokio, Tower, `inventory`, procedural macros using `syn`/`quote`, `trybuild`, and `cargo-llvm-cov`.

**Spec:** `docs/superpowers/specs/2026-08-21-v0.3-http-runtime-design.md`

## Global Constraints

- Execute exactly one Task per Executor session, mark it completed, and stop for review.
- Follow red-green-refactor: run each focused test before implementation and observe the stated failure.
- Keep `mads-core` free of Axum, Tower, Hyper, HTTP, `mads-common`, and all HTTP semantics.
- Preserve v0.2 concrete-type provider resolution, application scope, deterministic graph ordering, and construction behavior.
- Validate the complete route catalog before calling `Router::route`, starting lifecycle hooks, or binding a listener.
- Never dispatch by handler-name, trait-name, controller-name, or other strings.
- Preserve MADS `/:parameter` metadata syntax and translate only validated paths to Axum 0.8 `/{parameter}` syntax.
- Keep GET-to-HEAD, unsupported OPTIONS/405/Allow, static precedence, strict trailing slash, and default 404 behavior exactly as specified.
- Keep endpoint verbs direct; copy `cfg` and `cfg_attr` consistently to the trait method, metadata, and registrar.
- Keep `mads::core::Result` for framework/bootstrap operations and `HttpResult<T>` for handler responses.
- Every Rust file starts with `//!`; every public item has complete rustdoc; unsafe code remains forbidden.
- Preserve Rust 1.85 compatibility and at least 85 percent workspace LLVM line coverage.
- Use `apply_patch` for hand-written changes, preserve unrelated worktree changes, and stage only files belonging to the current Task.

#[allow(clippy::result_large_err)]
pub fn build_router(application: &mads_core::Mads) -> mads_core::Result<axum::Router> {
    let controllers = RouteCatalog::validated()?;
    let mut router = axum::Router::new();
    for controller in controllers {

}
